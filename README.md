Single Page Application (SPA) Simulation

A robust, lightweight, and modern Single Page Application (SPA) Simulation built using vanilla HTML5, CSS3, and JavaScript (ES6+). Developed as part of the Frontend Web Developer Internship final task.

🚀 Features

Client-Side Routing: Dynamic view injection and template swapping without triggering full browser page reloads.

History API Integration: Seamless support for browser URL hash updates, forward, and backward navigation (history.pushState and popstate event handling).

Modern Responsive UI: Polished CSS layout featuring custom variables, CSS Grid/Flexbox, card components, and smooth fade-in view transitions.

Interactive Views: Pre-configured views including Home Overview, Analytics Dashboard, User Profile, and Application Settings.

📁 Project Structure

spa-simulation-project/
│
├── index.html       # Main application shell containing sidebar and dynamic viewport
├── style.css        # Global styling, layout components, and animation keyframes
└── app.js           # Client-side router, view templates, and event handlers


🛠️ Getting Started & Usage

Clone or Download the project files (index.html, style.css, and app.js) into a single local directory.

Run Locally: Open index.html directly in any modern web browser, or launch it via a local development server (like VS Code Live Server) for the optimal experience.

Navigate: Click through the sidebar menu items (Home, Dashboard, Profile, Settings) to experience instant, reload-free client-side routing.
